# 涨停速览 · ZTPopup

盘中实时盯 A 股涨停板：**只在盘中首次上板时弹一次卡片**，右下角 3 秒自动关闭，不刷屏、不重复。

免安装 —— 从 [Releases](../../releases) 下载 `ZTPopup.exe`，双击即用，不需要装 Python。

![盘中弹窗](screenshots/toast.png)

## 功能

- **只提示盘中首次上板**：竞价阶段（09:30 前）已涨停的票，盘中即使炸板回封也不提示
- **同一只只弹一次**：炸板 → 回封 → 再炸 → 再回封，全程不重复
- **不补发轰炸**：盘中中途打开时，先把已涨停的票静默记入，只提示之后新上板的
- **状态窗可见**：右下角小窗常驻，实时显示当前阶段、数据日、涨停池只数、今日已提示数、上次扫描时间；任务栏有图标，一眼看出程序在跑
- **休市有明确提示**：非交易日打开会直接写明"今日休市，不会有盘中数据"，不会让你干等
- **干净退出**：14:57 自动结束；关闭状态窗即退出，不写注册表、不开机自启、不留后台进程
- **单实例**：重复双击只提示"已在运行"，不会开出第二个进程

## 使用

1. 下载 `ZTPopup.exe` 双击运行（无黑窗）
2. 交易日自动在 09:26 采集竞价涨停股作为去重基准，09:30–14:57 每 5 秒扫描涨停池
3. 有盘中新上板的个股即弹卡片；关闭状态窗退出

源码运行（需 Python 3.9+ 且带 tkinter）：

```bash
python zt_popup.py            # 正常监控
python zt_popup.py --demo     # 用最近交易日真实数据演示一次弹窗
```

## 数据源

东方财富涨停板池 `getTopicZTPool`，免费、无需 token、盘中准实时。请求失败按 2/5/8 秒退避重试，仍失败则降级使用上次缓存，不会崩窗。
